# عالمي الأخضر | MY GREEN WORLD

المرحلة الأولى: هيكل تطبيق Flutter عربي + بوابة Cloudflare Worker أولية.

## ما الموجود حالياً؟
- واجهة عربية RTL قابلة للتشغيل.
- شاشة رئيسية أولية بهوية خضراء.
- تبويبات: الرئيسية، موسوعتي، حديقتي، الإعدادات.
- بنية تخزين محلي بصيغة JSON (ملفات الهاتف، وليس قاعدة بيانات سحابية).
- هيكل Cloudflare Worker لا يحتوي أي مفاتيح سرية.
- GitHub Actions لإنتاج APK من المستودع دون الحاجة إلى تثبيت Flutter على الهاتف.

> هذه نسخة تأسيسية للمرحلة الأولى، وليست بعد تطبيق التعرف والتشخيص النهائي. أزرار التعرف والحديقة ستُفعّل في المراحل التالية.

## متطلبات البناء من الموبايل
أسهل مسار للمستخدم الذي يعمل من الهاتف:
1. فك ضغط الملف.
2. أنشئ مستودعاً جديداً في GitHub من المتصفح.
3. ارفع محتويات مجلد `mobile_app` إلى جذر المستودع (لا ترفع المجلد نفسه كطبقة إضافية).
4. ارفع مجلد `.github` الموجود بجانب `mobile_app` إلى جذر المستودع أيضاً.
5. من GitHub افتح تبويب **Actions** وفعّل Actions إذا طُلب منك.
6. شغّل سير العمل **Build Android APK**.
7. بعد نجاحه افتح نتيجة التشغيل ونزّل ملف `app-release.apk` من قسم Artifacts.

ملاحظة: أول رفع للمشروع يحتاج أن يكون `mobile_app` هو جذر مشروع Flutter داخل مستودع GitHub. ملف سير العمل يتولى إنشاء ملفات منصة Android ثم بناء APK.

## البناء محلياً
إذا توفر Flutter:
```bash
cd mobile_app
flutter create . --platforms=android
flutter pub get
flutter run
flutter build apk --release
```

## التخزين المحلي
المرحلة الأولى تجهّز خدمة JSON محلية باستخدام `path_provider`. لا توجد قاعدة بيانات مركزية ولا حسابات مستخدمين حالياً. صور النباتات ستُحفظ في مجلد التطبيق الخاص على الجهاز في مرحلة الكاميرا.

## Cloudflare Worker
المجلد `cloudflare_worker` يحتوي نقطة فحص `/health` ومسارات API أولية. لم تتم إضافة مفاتيح أو ربط مزودات التعرف بعد.
عند تجهيز الربط لاحقاً، تُضاف المفاتيح من Cloudflare Dashboard > Workers & Pages > Settings > Variables and Secrets > Add > Secret.
لا تضع المفاتيح داخل Flutter أو GitHub.

## ملاحظات مهمة
- التعرف على النباتات وتشخيص الأمراض يحتاجان اتصال إنترنت ومفاتيح API صالحة.
- لا توجد أي مفاتيح API ضمن هذا الملف.
- لا تعتمد على تشخيص آلي وحده لاستخدام مبيدات أو مواد كيميائية؛ يجب مراجعة التعليمات المحلية والملصق المختص.
